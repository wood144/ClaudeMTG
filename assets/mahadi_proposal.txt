# "Everything Must Go" — Mahadi, Emporium Master (Rakdos aristocrats: ping on entry, drain on exit)
# v2 of the Claude-style deck (replaces The Nightly Toll / Braids after playtest #1 + Ben's feedback).
# Built 2026-08-01 from collection.db only.
#
# Plan: every body pings each opponent on the way IN (Impact Tremors, Witty
# Roastmaster, Sharpshooter, Agate Instigator, Ayara) and drains on the way OUT
# (Blood Artist, Zulaport, Vraan, Falkenrath Noble, Judith, Garna). Mahadi turns
# each turn's deaths into Treasures — deaths ARE ramp. Recursive fodder loops
# through both trigger sets every turn. Red fixes the old deck's gaps: real
# instant removal (Terminate/Bedevil/Abrade), true wipes (Blasphemous Act with a
# recursive board is near one-sided; Chain Reaction), Rakdos Charm for GY decks,
# and Jeska's Will + Treasures into a lethal Exsanguinate. Still no combat math:
# the deck wins standing completely still.
